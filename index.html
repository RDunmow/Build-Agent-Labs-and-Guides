A ServiceNow Studio Workshop Series

Pub Quiz Manager &
Friends

A series of hands-on workshops that build, extend, and AI-power a complete Pub Quiz Manager application in ServiceNow.

This bundle collects the full Pub Quiz Manager workshop trilogy in one place. Each part stands on its own, but they're best taken in order — every workshop builds on the application produced in the one before.

The arc is deliberate: start with Build Agent to scaffold the app, layer on AI Skills to generate content, and finish by wrapping the lot in an agent that runs the whole flow from a single sentence.
